# Manuscript figure code

See [the step-by-step workflow](WORKFLOW.md) for analysis order, required
upstream results, expected output types and the current execution scope.

The notebooks and R scripts are organized by analysis group in `figure2/`
through `figure6/`. `data- preprocess.ipynb` and `elbow-gene-choose.ipynb`
contain upstream preparation and feature-count analysis. The directory labels
reflect the author's current organization; the final mapping to manuscript
panel numbers still needs author confirmation. Model training is documented in
the [main README](../README.md).

## Inputs and outputs

The figure analyses require external datasets, gene lists, benchmark results,
intervention inputs, and intermediate tables. They are **not** all in GitHub
and are not all generated by `run_cross_validation.py`. See the
[figure input inventory](INPUTS.md) for paths referenced by each script.

The code uses `SAGE_FIGURE_INPUT_ROOT` for required inputs and
`SAGE_FIGURE_OUTPUT_ROOT` for generated results. By default these are
`figure_inputs/` and `figure_outputs/` under the repository root; both are
ignored by Git. Populate the listed relative paths under `figure_inputs/`, or
set the input root to a directory that already contains the same layout.
For example, the author's original Windows drive can be selected in Command
Prompt with `set SAGE_FIGURE_INPUT_ROOT=E:/`; WSL can use
`export SAGE_FIGURE_INPUT_ROOT=/mnt/e`. Set
`SAGE_FIGURE_OUTPUT_ROOT` if you want results outside the repository.
`SAGE_FIGURE_FONT` optionally selects a TrueType font file; otherwise the
code uses Matplotlib's DejaVu Sans font.

Some preprocessing and benchmark notebooks write derived files into their
input layout. Copy the required source files into the ignored
`figure_inputs/` tree before executing those upstream notebooks. Pointing the
input root at an author's original drive is suitable for inspecting existing
files; first make a working copy if you will rerun steps that write results.

Run Jupyter and R commands from the **repository root**. The notebooks import
`figure.paths`; R scripts source `figure/paths.R`. Paths in the source code
resolve against the configured roots rather than an author's machine path.
Some notebooks have several analysis sections; supply their upstream inputs
and run cells in order. Data accessions, file checksums, and exact figure
reproduction remain to be documented.

## Python installation

Install the model environment from the [main README](../README.md), then add
optional figure packages in the same active environment:

```bash
python -m pip install -r requirements-figures.txt
python -m pip check
python -m ipykernel install --user --name sage --display-name "Python (sAge)"
jupyter lab
```

With Conda on a machine that has user-level Python packages, use `python -s`
for the pip check and figure commands as explained in the main README.
Open notebooks from `figure/` and select **Python (sAge)**. The optional
dependency ranges are an installation starting point, not a manuscript
version lock. The [validation record](VALIDATION.md) identifies the one
notebook and helper executed with local cached data; the remaining figure
results have not been independently validated.

## R installation

Install R and these packages before running the R scripts:

```r
install.packages(c("BiocManager", "tidyverse", "RColorBrewer", "pheatmap", "proxy"))
BiocManager::install(c("AnnotationDbi", "GOSemSim", "clusterProfiler",
                      "org.Hs.eg.db", "org.Mm.eg.db", "ComplexHeatmap"))
```

For example, run `Rscript figure/figure4/1-mouse-gene-upset-tissue.R` from
the repository root after configuring the input directories. `grid`, `stats`,
and `tools` are part of R. Record `sessionInfo()` with reproduced results;
the original manuscript R/Bioconductor versions are not yet known.

## Script index

| Location | Analysis |
| --- | --- |
| `data- preprocess.ipynb` | Human dataset preprocessing |
| `elbow-gene-choose.ipynb` | Feature-count selection |
| `figure2/` | Mouse/human MLP benchmarks, heatmaps and boxplots |
| `figure3/` | Gene-expression trajectories and GO clusters |
| `figure4/` | Tissue gene ratios, gene-set overlap and GO analyses |
| `figure5/figure-5-1-plasma.ipynb` | Plasma and age-stratified tissue communication panels |
| `figure6/` | Clocks, rapamycin, caloric restriction and target genes |
| `figure5/cellphonedb_interaction_count_network.py` | CellPhoneDB network helper and analysis |

The CellPhoneDB helper module was recovered from the author's analysis
directory and now ships with the notebooks. Run it from the repository root
with `python -m figure.figure5.cellphonedb_interaction_count_network` **only after**
supplying its input CSV files described in [INPUTS.md](INPUTS.md). The plasma
notebook also requires cached age-stratified tables; it does not rerun
CellPhoneDB.

Cached notebook outputs and execution counts were cleared before source
publication. See the [figure validation record](VALIDATION.md): the recovered
CellPhoneDB helper and complete plasma notebook ran with the author's local
cached data, while the other analyses received format and syntax checks only.
This does not establish that every manuscript figure can be reproduced. Some
`gseapy` and `mygene` enrichment calls use external services; record database
versions and responses when reproducing results.
